# Voice Sample Audio Files

This directory should contain the following audio sample files for voice preview functionality:

## Required Files:
- `polly-sample.mp3` - Sample of Amazon Polly voice quality
- `elevenlabs-sample.mp3` - Sample of ElevenLabs voice quality  
- `custom-sample.mp3` - Sample of custom voice cloning quality

## Audio Specifications:
- Format: MP3
- Duration: 10-15 seconds each
- Content: Sample text demonstrating voice quality and naturalness
- Sample text suggestion: "Hello, this is a sample of our translation voice quality. Listen to how natural and clear the pronunciation is."

## Notes:
- If audio files are not available, the JavaScript will show "Sample not available" message
- Audio files should be optimized for web streaming (compressed MP3 format)
- Consider providing multiple language samples if targeting international users
